宅配シミュレーター プライバシーポリシー

「宅配シミュレーター」（以下「本アプリ」）は、かぴばらの湯（個人）が開発・運営しています。本アプリが扱う情報と、その使い道を次のとおり定めます。

1. 端末の中に保存する情報

ゲームの進み具合（所持金・強化・車の装備と色・設定・実績・ドライバー名）は、お使いの端末の中に保存します。あわせて、同じ端末でアプリを入れ直した時や、万一サーバーのデータを元に戻した時に続きから遊べるよう、プレイヤー ID と復元用の鍵を端末の中に保存します（iPhone では、アプリを消しても残る安全な保管場所（キーチェーン）に保存します）。

2. 運営のサーバーに保存する情報

本アプリは、データの保管サービス（Supabase 社のサービス）を使って、次の情報を保存します。

  • プレイヤー ID（アプリが自動で作るランダムな番号。氏名やメールアドレスとは結びつきません）
  • ドライバー名
  • チュートリアルの報酬を受け取った記録
  • ゲームの進み具合の控え（端末のセーブデータの写し。ガレージに戻った時などに自動で保存します）
  • 引き継ぎのパスワード（決めた場合。元に戻せない形に変えて保存します）・復元用の鍵（元に戻せない形）
  • 購入の記録（カスタムパックなど。どのプレイヤー ID が何を買ったか）
  • お問い合わせの内容（本文・添付した写真・送ったときのアプリの版と端末の種類・言語・返信用のメールアドレス（任意））と、運営からのお返事
  • アプリで起きた不具合の記録（エラーの内容・その時の画面・アプリの版・端末の種類と OS の版。90 日で自動で消えます）

ゲームの進み具合の控えと、アカウントを元に戻すのに要る情報（プレイヤー ID・ドライバー名・チュートリアルの報酬を受け取った記録・購入の記録・引き継ぎのパスワードと復元用の鍵（どちらも元に戻せない形））は、万一に備えて、1 日 1 回、バックアップ用の保管サービス（Backblaze 社のサービス）にも写します。

これらのサービスのサーバーは、日本国外（アメリカなど）にあることがあります。

3. テスト版で送る情報（テスト版のみ）

テスト版では、テスターの方への特典と不具合の調査のために、次の情報をデータの保管サービス（Supabase 社のサービス）へ送ります。

  • ランダムな利用者 ID（アプリが自動で作るもので、氏名やメールアドレスとは結びつきません）
  • テスターの名簿：ドライバー名と、それに対して発行するテスター番号
  • 「バグを報告」で送った内容：報告の文、添付した写真（任意）、送ったときのゲームの状況（日付・場所・荷物の状態など）、動きのなめらかさ（FPS）、アプリの版、端末の情報（ブラウザの種類、画面の大きさ、アプリ版かブラウザ版か）、端末ごとのランダムな ID
  • チュートリアルの報酬を受け取った記録

これらは、テスター特典の受け渡しと不具合の調査が終わったあと、削除します。

4. オンラインプレイ（協力・バトル）で送る情報

協力・バトルで遊ぶときは、相手の画面に表示するために、ドライバー名・車の装備と色・ゲーム内の位置と成績を、中継サーバー（Render 社のサービス上）へ送ります。これらは部屋が終わると消え、保存はしません。通信の仕組み上、中継サーバーに接続元の IP アドレスが一時的に記録されることがあります。

5. 広告

本アプリは、Google 社の広告サービス「AdMob」を使って広告を表示します。AdMob は、広告の表示と効果の測定のために、端末の広告 ID・IP アドレス・端末の種類などの情報を使うことがあります。

iPhone では、アプリが最初に「トラッキングの許可」をお尋ねします。許可しなくても、本アプリは問題なく遊べます（あなたに合わせない広告が表示されます）。設定の「広告の設定」から、いつでも選び直せます。

Google 社による情報の扱い：https://policies.google.com/technologies/ads

6. アプリ内課金

アプリ内課金の支払いは、Apple 社（App Store）または Google 社（Google Play）が行います。本アプリがカードの番号などの支払い情報を受け取ることはありません。購入の確認には RevenueCat 社のサービスを使い、プレイヤー ID と購入の記録をやりとりします。

7. 情報の使い道

  • ゲームの進み具合・購入した物を保つため、引き継ぎのため
  • オンラインプレイのため
  • お問い合わせへの返信と、不具合の調査のため（返信用のメールアドレスを書いた方には、メール送信サービス（Resend 社のサービス）を使ってメールでもお返事します）
  • 広告の表示のため
  • 不正な利用を防ぐため

8. 取得しない情報

氏名・電話番号・住所・位置情報（GPS）・連絡先・写真（お問い合わせで自分から添付したものを除く）は取得しません。

9. 第三者への提供

法令にもとづく場合を除き、上の情報を第三者に販売・提供することはありません。Supabase 社・Backblaze 社・Resend 社・Cloudflare 社・Render 社・Google 社・RevenueCat 社・Apple 社は、本アプリの運営のために利用している外部のサービスです。

10. 保存の期間と削除

  • サーバーに保存した情報は、アプリを削除（アンインストール）しても消えません。同じ端末やプレイヤー ID で、続きから遊べるようにするためです。
  • 最後にご利用になってから 2 年たった情報は、自動で削除します。
  • アカウントの削除は、アプリの「設定」→「アカウントの削除」から行えます。サーバーの情報はすぐに削除します。アプリを削除してしまった場合の方法は「アカウントの削除」のページ（https://capybaranoyu.com/delivery/delete-account/）をご覧ください。
  • 削除した情報は、バックアップの中に最長 3 か月残り、その後自動で消えます。

11. お子さまの利用

本アプリは、どなたでも遊べるゲームです。13 歳未満の方は、保護者の方の同意のうえでご利用ください。

12. お問い合わせ

または、アプリの「設定」→「お問い合わせ」

13. 改定

本ポリシーは、必要に応じて改定します。大切な変更は、アプリ内のお知らせでお知らせします。
