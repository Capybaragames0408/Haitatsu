宅配シミュレーター プライバシーポリシー

本アプリ「宅配シミュレーター」（以下「本アプリ」）は、個人で開発・運営しています。本アプリが扱う情報と、その使い道を次のとおり定めます。

1. 端末の中に保存する情報

ゲームの進み具合（所持金・強化・車の装備と色・設定・実績・ドライバー名）は、お使いの端末の中に保存します。アプリを消したり、ブラウザのサイトのデータを消したりすると、この情報も消えます。

2. オンラインプレイ（協力・バトル）で送る情報

協力・バトルで遊ぶときは、相手の画面に表示するために、ドライバー名・車の装備と色・ゲーム内の位置と成績を、中継サーバー（Render 社のサービス上）へ送ります。これらは部屋が終わると消え、保存はしません。通信の仕組み上、中継サーバーに接続元の IP アドレスが一時的に記録されることがあります。

3. テスト版で送る情報（テスト版のみ）

テスト版では、テスターの方への特典と不具合の調査のために、次の情報をデータの保管サービス（Supabase 社のサービス）へ送ります。

  • ランダムな利用者 ID（アプリが自動で作るもので、氏名やメールアドレスとは結びつきません）
  • テスターの名簿：ドライバー名と、それに対して発行するテスター番号
  • 「バグを報告」で送った内容：報告の文、添付した写真（任意）、送ったときのゲームの状況（日付・場所・荷物の状態など）、動きのなめらかさ（FPS）、アプリの版、端末の情報（ブラウザの種類、画面の大きさ、アプリ版かブラウザ版か）、端末ごとのランダムな ID
  • チュートリアルの報酬を受け取った記録

これらは、テスター特典の受け渡しと不具合の調査が終わったあと、削除します。

4. 取得しない情報

氏名・メールアドレス・電話番号・住所・位置情報（GPS）・連絡先・端末の広告 ID は取得しません。

5. 第三者への提供

法令にもとづく場合を除き、上の情報を第三者に提供・販売することはありません。中継サーバー（Render 社）とデータの保管（Supabase 社）は、本アプリの運営のために利用している外部のサービスです。

6. 広告・課金

現在、外部の広告会社への情報の送信と、アプリ内課金はありません。導入するときは、このポリシーを改定してお知らせします。

7. 削除の依頼・お問い合わせ

送った情報の削除の依頼やお問い合わせは、アプリ内の「バグを報告」からお送りください。

8. 改定

このポリシーは、必要に応じて改定します。大切な変更は、アプリ内のお知らせでお知らせします。
